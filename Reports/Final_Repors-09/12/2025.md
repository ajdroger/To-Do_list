
# Relazione Tecnica: TaskMaster AI Android
**Data:** 09/12/2025
**Versione:** 2.1 (Dark Mode Support)

## 1. Introduzione
Questo documento descrive in dettaglio l'architettura tecnica, le scelte di design e l'implementazione del codice per l'applicazione "TaskMaster AI". L'app è una To-Do List avanzata progettata per dispositivi mobili (stile Android/Material You) che utilizza l'Intelligenza Artificiale di Google Gemini per assistere l'utente nella gestione delle attività.

## 2. Architettura Tecnologica
Il progetto è una **Single Page Application (SPA)** basata su:
*   **Framework:** React 19
*   **Linguaggio:** TypeScript (per la tipizzazione statica robusta)
*   **Styling:** Tailwind CSS (per un design system rapido e responsivo)
*   **AI SDK:** `@google/genai` (Google Gemini API)
*   **Icone:** Lucide React
*   **Persistenza:** LocalStorage (browser-based)

## 3. Struttura dei File e Analisi del Codice

### 3.1 `types.ts` (Modello Dati)
Definisce le interfacce fondamentali dell'applicazione.
*   **`Task`**: L'oggetto principale. Include `id`, `title`, `description`, `priority`, e due array fondamentali:
    *   `subtasks[]`: Lista dei passaggi generati dall'AI.
    *   `chatHistory[]`: **Nuova aggiunta**. Mantiene la cronologia della conversazione con l'AI specifica per quella task. Questo permette all'AI di avere "memoria" del contesto.
*   **`ChatMessage`**: Struttura dei messaggi (ruolo utente/modello, testo, timestamp).

### 3.2 `services/geminiService.ts` (Il "Cervello" AI)
Questo file gestisce tutte le comunicazioni con le API di Google Gemini.

*   **Configurazione**: Inizializza il client con `new GoogleGenAI({ apiKey: process.env.API_KEY })`.
*   **`generateSubtasks(taskTitle)`**:
    *   Usa il modello `gemini-2.5-flash` per velocità ed efficienza.
    *   **Prompt Engineering**: Istruisce il modello ad agire come esperto di produttività e risponde con un JSON schema (`Type.ARRAY`) per garantire che l'output sia sempre una lista di stringhe valida, evitando errori di parsing.
*   **`chatWithTaskAi(task, userMessage, history)`**:
    *   Questa funzione rende l'AI "contestuale".
    *   **Context Injection**: Prima di inviare il messaggio dell'utente, costruisce un prompt di sistema dinamico che contiene tutti i dettagli della task corrente (titolo, descrizione, stato subtask).
    *   *Esempio Prompt Sistema:* "Sei un assistente... L'utente chiede aiuto su: [Titolo Task]...".
    *   Questo permette all'AI di dare risposte come: "Vedo che hai completato 2 step su 3, ti manca solo X".

### 3.3 `App.tsx` (Orchestratore)
Il componente radice che gestisce lo stato globale.

*   **Gestione Stato**: Usa `useState` per tasks, filtri, modali e **tema (Dark Mode)**.
*   **Persistenza**: Utilizza `useEffect` per leggere/scrivere l'array `tasks` nel `localStorage`.
*   **Gestione Tema (Dark Mode)**:
    *   Controlla la preferenza di sistema (`prefers-color-scheme`) e il `localStorage`.
    *   Applica la classe `dark` all'elemento `<html>`.
*   **Layout**:
    *   **Header Dinamico**: Mostra il pulsante di switch tema (Sole/Luna), il saluto e la barra di progresso.
    *   **Routing simulato**: Gestisce la navigazione tra "Lista Task" e "Tutorial".

### 3.4 `components/TaskItem.tsx` (Interfaccia Attività)
Rappresenta la singola card dell'attività.

*   **Design**: Implementa un effetto "fisarmonica" (accordion).
*   **Dark Mode**: Utilizza le varianti `dark:` di Tailwind per adattare colori di sfondo (`bg-slate-800`), testo (`text-slate-100`) e bordi.
*   **Integrazione AI**: Mostra pulsanti per generare subtask o aprire la chat.

### 3.5 `components/TaskChatModal.tsx` (Interfaccia Chat Proattiva)
Una modale full-screen (o bottom-sheet su mobile) per conversare con l'assistente.

*   **Logica**: Inserisce messaggio di benvenuto automatico se la chat è vuota.
*   **Optimistic UI**: Aggiorna la lista messaggi immediatamente all'invio.
*   **Stile**: Adattato completamente al tema scuro, inclusi i campi di input e le bolle della chat.

### 3.6 `components/AddTaskModal.tsx`
Form per la creazione di nuove attività.
*   Design "Bottom Sheet" moderno con sfocatura (`backdrop-blur`).
*   Supporto completo Dark Mode per input testuali e pulsanti.

### 3.7 `components/TutorialView.tsx`
Pagina informativa statica.
*   Spiega la differenza tra PWA (Aggiungi a Home) e APK nativo.
*   Testi e sfondi ottimizzati per la leggibilità notturna.

## 4. Design System & UX (Stile Android)
L'applicazione segue i principi del Material Design moderno ("Material You") adattato con Tailwind CSS.

*   **Color Palette**:
    *   Primario: Indigo/Violet (`indigo-600`, `violet-600`) per azioni principali e AI.
    *   Sfondo Light: Slate (`slate-50`, `white`).
    *   Sfondo Dark: Slate (`slate-950`, `slate-900`, `slate-800`).
    *   Priorità: Emerald (Bassa), Amber (Media), Rose (Alta).
*   **Forme**: Uso intensivo di `rounded-2xl` e `rounded-3xl` per evocare l'estetica delle app Android native.

## 5. Implementazione Dark Mode
La modalità scura è implementata utilizzando la strategia `class` di Tailwind CSS.
1.  **Configurazione**: Nel file `index.html`, la configurazione di Tailwind include `darkMode: 'class'`.
2.  **Rilevamento**: All'avvio, l'app controlla se esiste una preferenza salvata in `localStorage` o usa `window.matchMedia` per la preferenza di sistema.
3.  **Attivazione**: Quando attiva, viene aggiunta la classe CSS `dark` al tag `<html>`.
4.  **Stili**: Ogni componente definisce stili specifici con il prefisso `dark:` (es. `bg-white dark:bg-slate-800`).

## 6. Guida alle Funzionalità AI

### Generazione Sotto-attività (Subtasks)
1.  L'utente clicca "Suggerisci passaggi con AI".
2.  **Input**: Titolo della task.
3.  **Processo**: Gemini analizza la richiesta e la scompone in step atomici.
4.  **Output**: Checkbox per ogni step.

### Chat Contestuale (Proactive AI)
1.  L'utente clicca sull'icona della chat.
2.  **Contesto**: L'AI riceve i dati della task e risponde coerentemente.
3.  **Memoria**: La conversazione persiste nell'oggetto `Task`.

## 7. Installazione e Distribuzione

### PWA (Progressive Web App)
Il file `index.html` include i meta tag necessari. Installabile tramite browser Chrome su Android.

### APK (Android Package)
Predisposto per **CapacitorJS**. Comandi: `npm install ...`, `npx cap add android`, `npx cap open android`.
